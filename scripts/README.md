# Инструменты

Обычные скрипты, которые работают без агента — их запускает расписание ОС (cron / launchd). Агент не «демон»: у него нет часов, он живёт только в чате.

## nightly-push.sh

«Ночной работник» мозга: записывает накопленное (правки в заметках, заметки агента) и отправляет в облако. Токены чата не тратятся — работает без агента.

```bash
bash scripts/nightly-push.sh
```
Что произойдёт: если в репозитории есть изменения — коммит `nightly: авто-сохранение <дата>` и push; лог пишется в `~/.agent-core-nightly-push.log`.

Путь к репозиторию задаётся переменной `AGENT_CORE_HOME` (по умолчанию `~/agent-core`).

Расписание (по желанию):

- **macOS (launchd):** plist в `~/Library/LaunchAgents/`, указывающий на этот скрипт (например, каждый день в 03:30). Если машина спала — запуск перенесётся на пробуждение.
- **Linux (cron):** `30 3 * * * bash ~/agent-core/scripts/nightly-push.sh` (`crontab -e`).

## web-digest.py

Дайджест веб-страницы вместо целой страницы — экономит контекст (лимиты). Целые страницы попадают в контекст по 100–150 тыс. символов и оплачиваются в каждом следующем запросе; дайджест даёт заголовок, подзаголовки и начало текста — обычно этого хватает, чтобы вынести вердикт.

```bash
python3 scripts/web-digest.py <url>                    # заголовок + подзаголовки + ~4000 символов
python3 scripts/web-digest.py <url> --chars 8000       # больше текста
python3 scripts/web-digest.py <url> --grep <слово>     # разделы/абзацы со словом (лучший способ достать факт)
python3 scripts/web-digest.py <url> --headings         # только заголовки
python3 scripts/web-digest.py <url> --full             # весь текст (когда реально нужен целиком)
```

Зависимостей нет — только стандартная библиотека Python 3.
