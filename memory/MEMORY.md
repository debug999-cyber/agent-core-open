# MEMORY — индекс памяти

Короткая память: читаешь первым (файл маленький). Дальше иди в файлы, которые нужны задаче.

## Пользователь (главное)

- Язык: … (на каком языке общаться)
- Уровень: … (насколько можно углубляться в детали)
- Git: коммиты от имени `…`
- Подробнее: `user.md`.

## Как общаться и работать

- `preferences.md` — формат общения, что ценно, чего не хотим.

## Текущая ситуация

- `context.md` — что сейчас происходит и что дальше. **Обновлять в конце каждой сессии!**

## Журналы (append-only)

- `decisions.md` — важные решения и почему.
- `lessons.md` — уроки из ошибок. Урок, повторившийся 2+ раза, → превращается в скилл.

## Карта репозитория

- `START.md` — пропуск (точка входа для любого чата).
- `skills/` — ящик с инструментами (как делать).
- `mcp/` — «руки»: что уже есть у агента + конфиги для клиентов.
- `hooks/` — страховки. `scripts/` — инструменты. `changelog.md` — дневник (что сделано).

## Ключевые правила

- Токены — никогда в файлах и коммитах. Секреты живут вне репозитория.
- Деструктивные операции — только с подтверждения.
