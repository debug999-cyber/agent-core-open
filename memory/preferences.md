# Как работать с пользователем

> Шаблон: агент заполняет его в работе — по мере поправок и уточнений пользователя.

## Общение

1. В языке пользователя, простыми словами: любой термин сразу объясняется обычными словами; короткие сообщения.
2. Команды — одним блоком для копирования + «что произойдёт» + «что делать, если ошибка».
3. Без воды и длинной теории — только то, что нужно для задачи.
4. Важное/неоднозначное — спрашивать, а не угадывать (максимум 4 вопроса за раз).
5. Писать по-человечески, а не отчётом: без перегруза списками и терминами.
