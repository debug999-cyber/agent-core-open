# Хуки

«Страховки», которые срабатывают автоматически — чтобы ошибки не дошли до последствий.

## pre-commit-check.sh

Локальный git-хук. Блокирует коммит, если:

- в добавляемые файлы попал токен GitHub (`ghp_…`, `github_pat_…`) или другое, что похоже на секрет;
- в коммит собирается файл, похожий на секрет (`.env`, `*.key`, `*.pem`, `id_rsa`, `credentials`).

### Установка (в этом репозитории, на каждой машине)

```bash
cp hooks/pre-commit-check.sh .git/hooks/pre-commit && chmod +x .git/hooks/pre-commit
```
Что произойдёт: перед каждым коммитом пройдёт проверка; при находке коммит отклонится с объяснением.

### Важно

`.git/hooks` — локальная папка, она не попадает в git. После нового клона хук ставится заново (команда выше).

## Идеи на вырост

- Хук-напоминание: если в сессии менялись файлы `memory/` — автоматически добавить метку в сообщение коммита.
- Хук «линтер памяти»: проверять, что `context.md` содержит свежую дату, прежде чем пушить.
