# Руки

Чем агент **делает**, а не только говорит.

## Уже есть у агента (ничего ставить не надо)

- **Твой GitHub** — git + API (репозитории, файлы, коммиты, issues).
- **Песочница агента** — Python, Node, файлы, код, запуск скриптов.
- **Веб** — поиск и чтение страниц.
- **Генерация** — картинки и голос (если у клиента есть).
- **Живой предпросмотр** — страницы и дашборды прямо в твоём браузере.

## Конфиги для твоих клиентов

Если хочешь, чтобы агент в твоих клиентах работал с твоим GitHub — поставь эти конфиги:

- `configs/cline.json` — Cline. GitHub идёт через облачный сервер `api.githubcopilot.com/mcp` — Docker не нужен.
- `configs/claude-desktop.json` — Claude Desktop. GitHub через Docker + твой PAT.
- `configs/cursor.json` — Cursor. То же, что Claude Desktop.

Токен вписать в место `<СЮДА_ТОКЕН>` в конфиге **клиента** (он лежит на твоей машине) — не в этом репозитории: хук заблокирует коммит с токеном.

## Твои заметки (Obsidian)

Если у тебя Obsidian — заметки доходят до агента **через Git**: хранилище (vault) — это git-репозиторий. Агент клонирует → правит заметки как файлы → пушит, и Obsidian подхватывает изменения. Для прямого доступа нужен плагин **Local REST API** (Coddington Bear) и его ключ в конфиге (см. `configs/claude-desktop.json`, `configs/cursor.json`).

## Если нужен свой MCP-сервер

Если какой-то инструмент нужно сделать доступным из твоих клиентов (Claude Desktop / Cursor), а готового сервера нет, агент напишет свой (Python, FastMCP). Типичные случаи: доступ к твоему vault, твои личные сервисы. Назови задачу — сделаю.
