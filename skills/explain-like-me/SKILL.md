# explain-like-me

Каждую команду передавать пользователю так:

1. **Один блок** — вся команда (или набор) для копирования целиком, не дробить по сообщениям.
2. **«Что произойдёт»** — 1–3 предложения простыми словами, без жаргона.
3. **«Если будет ошибка»** — самая вероятная ошибка и что с ней делать (одна строка).

Пример:

```bash
git clone https://github.com/<пользователь>/<репо>.git
```
Что произойдёт: в текущую папку скачается копия репозитория.
Если ошибка: если видите «fatal: not a git repository» — вы в чужой папке, сначала `cd` в нужную.

Не делать:

- выдавать цепочки команд без объяснения;
- писать «просто запусти» без «что произойдёт»;
- использовать английский термин без перевода при первом упоминании.

Уровень простоты — под пользователя (записан в `memory/user.md`): новичку — подробнее и с метафорами, специалисту — короче.
