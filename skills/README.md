# Скиллы

Формат: открытый стандарт Agent Skills: каждый скилл = папка с `SKILL.md` (frontmatter `name` + `description`, дальше инструкция). По описанию агент решает, когда открыть скилл — в контекст попадает только нужное.

## Что в комплекте

| Скилл | Когда срабатывает |
|---|---|
| `plan-first` | любая нетривиальная задача |
| `explain-like-me` | команды пользователю, объяснение технических вещей |
| `github-ops` | git/GitHub-операции |
| `memory-update` | конец сессии |
| `memory-hygiene` | «медосмотр» памяти: дубли, повторяющееся → правило, устаревшее |
| `self-improve` | после ошибки, новый паттерн, «само-чек» |
| `check-before-install` | перед установкой чужого скилла / MCP-сервера / хука |
| `documents` | создание/чтение Word, PDF, PPT, Excel |

## Как добавить скилл

1. Скопировать `templates/skill-template.md` в `skills/<имя>/SKILL.md`.
2. Написать `description`: что делает + «используй когда…» — по нему агент решает, открывать ли скилл.
3. Инструкция: нумерованные шаги, шаблоны, крайние случаи.
4. Коммит: `skill: добавлен <имя>`.

## Правила

- Скилл компактный; большой контекст — в отдельные файлы в папке скилла.
- Скилл обновляется, когда меняется реальность (а не память).
- Тест хорошего скилла: новый агент без контекста делает задачу по нему правильно с первого раза.

## Чужие скиллы и upstream

- Перед установкой любого чужого скилла или MCP-сервера — пройти чек-лист `check-before-install`.
- Для углублённых случаев — официальные скиллы (github.com/anthropics/skills: docx, pdf, pptx, xlsx, mcp-builder, skill-creator и др.). В наш репозиторий их **не копируем** (proprietary-лицензия) — смотрим как референс.
