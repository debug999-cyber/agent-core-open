# memory-update

## Протокол (конец сессии)
1. `memory/context.md` — переписать «Сейчас»: что сделано, что дальше, что не подтверждено. Свежая дата.
2. `memory/decisions.md` — добавить важные принятые решения (новые сверху).
3. `memory/lessons.md` — добавить новые уроки (новые сверху).
4. `memory/user.md` / `preferences.md` — только если появились **постоянные** новые факты (не дублировать).
5. `memory/MEMORY.md` — если «кто пользователь» или карта проектов изменилась, обновить индекс.
6. Закоммитить и запушить:
```bash
git add -A && git commit -m "memory: <что изменилось>" && git push
```

## Правила
- Append-only файлы (decisions, lessons) — историю не переписывать; исправления — новой записью «исправление к …».
- В память — никогда токены, пароли, ключи, приватные данные третьих лиц.
- Не записывать очевидное и то, что уже есть в файле.
- Если память нечего обновлять — честно сказать пользователю, что память не изменилась.
